1. C12 Beton — Temel Elastik Parametreler

Karot testinden elde edilen fck=12 MPa değeri, TBDY 2018 ve TS 500 kapsamında aşağıdaki parametrelere dönüştürülür:

TBDY 2018 / TS 500 — C12 Beton Parametreleri
fck = 12 MPa (karakteristik silindir dayanımı — karot sonucu) fcd = fck/γc = 12/1.5 = 8 MPa (tasarım dayanımı) fctk = 0.35 × √fck = 0.35 × √12 = 1.21 MPa (çekme dayanımı) Ec = 5000 × √fck = 5000 × √12 = 17.321 MPa (elastisite modülü) ν = 0.2 (Poisson oranı) γ = 25 kN/m³ (birim hacim ağırlık)
SAP2000 — Malzeme Tanımı
Define → Materials → Add New Material
  Material Type: Concrete
  fc' = 12 MPa  ← karot sonucu
  Ec  = 17321 MPa  ← hesaplanan
  ν   = 0.2
  Unit Weight = 25 kN/m³

⚠️ C12 Betonun Kritik Zayıflığı

C12 beton, modern yapılarda kullanılan C25-C30'un yarısından az dayanıma sahiptir. Elastisite modülü de yaklaşık %70 daha düşüktür. Bu durum yapının rijitliğini ve enerji yutma kapasitesini önemli ölçüde azaltır.

2. Doğrusal Olmayan Malzeme Davranışı — Mander Modeli

C12 gibi düşük dayanımlı beton için doğrusal olmayan analizde Mander Modeli kullanılır. Sargısız (cover) ve sargılı (core) beton ayrı ayrı tanımlanır.

2.1 Sargısız Beton (Cover)

Sargısız Beton Parametreleri
f'co = fck = 12 MPa (pik dayanım) εco = 0.002 (pik gerinim) εcu = 0.004 (kopma gerinimi — C12'de çok düşük!)

2.2 Sargılı Beton (Core) — Ø8/20 Etriye İçin

Mander Modeli — Sargılı Beton Hesabı
Ke = 0.75 (sargı etkinlik katsayısı) ρs = 4×(π×8²/4) / (300×200) = 0.0034 (hacimsel etriye oranı) fl = 0.5 × Ke × ρs × fyh = 0.5 × 0.75 × 0.0034 × 420 = 0.54 MPa f'cc = fco × (2.254×√(1+7.94×fl/fco) - 2×fl/fco - 1.254) = 12 × 1.18 = 14.1 MPa (sargılı beton dayanımı) εcc = εco × (1 + 5×(f'cc/f'co - 1)) = 0.002 × (1 + 5×0.18) = 0.0038 εccu = 0.004 + 1.4×ρs×fyh×εsm/f'cc ≈ 0.012
SAP2000 — Mander Modeli Girişi
Define → Materials → [C12] → Modify/Show Material
  → Nonlinear Material Data
  → Stress-Strain Curve: Mander
    Cover: fc=12, εco=0.002, εcu=0.004
    Core:  fc=14.1, εco=0.0038, εccu=0.012

💡 Kritik Not: εcu=0.004

C12 betonda kopma gerinimi εcu=0.004 çok düşüktür. İyi detaylı C25 betonda bu değer 0.018-0.020'ye ulaşır. Bu fark, plastik mafsal kapasitesini doğrudan etkiler ve C12 betonda erken hasar oluşmasına neden olur.

5. Pushover Analizi Kurulumu

SAP2000 — Pushover Analizi
Define → Load Cases → Add New Load Case
  Load Case Type: Nonlinear Static
  
  Initial Conditions: Continue from Dead Load
  
  Load Application:
    Type: Displacement Control
    Monitored DOF: U1  (X yönü)
    Target Displacement: H/50 = 3000/50 = 60 mm
    
  Load Pattern:
    Modal  (1. mod şekli — TBDY 2018 önerisi)

Analiz sonrası plastik mafsal renkleri:
  Yeşil:   Minimum Hasar (HK)
  Sarı:    Belirgin Hasar (KH)
  Turuncu: İleri Hasar (GÖ)
  Kırmızı: Göçme (G) ← C12+ZD kombinasyonunda erken!
